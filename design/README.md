## `pitchlog-tokens.css`

Claude Design 시안 내보내기(`exports/pitchlog-league/pitchlog.css`)를 승격한 것이다.
2026-09-03 대비 실측 후 2건을 수정했다. **원본은 `exports/` 에 손대지 않고 그대로 둔다.**

담고 있는 것:

- 브랜드 3단계 (라이트 `#3366FF` / 다크 `#6E93FF`)
- 표면·텍스트·구분선
- 순위 구역 6색 (`--z-*`) · 상태 3색 (`--st-*`)
- 간격 9단계 · 모서리 3종 · 그림자 3종
- 타입 스케일 7종
- 컴포넌트 CSS — 카드 · 칩 · 버튼 · 링크 · 배지 8종 · 스켈레톤 · 순위 행 · 폼 배지

## 지켜지고 있는 규칙

시안에서 확인된 것들이다. 구현할 때도 유지한다.

- **파랑 형태 분리** — 브랜드는 채움/밑줄, 구역은 좌측 2px 표시선 + 4% 틴트 (PRD 9-2)
- **활성 칩은 채운다** — 틴트가 아니다
- **구역은 색 + 패턴** — `data-pat="dash|dot|block"` 병용
- **재검증 배지에 사선 무늬** — 색상 외 단서
- 터치 타깃 44px · `:focus-visible` 2px+2px · `prefers-reduced-motion`
- 긴 팀명 — 축약 사전 → 말줄임 (`.tname`)
