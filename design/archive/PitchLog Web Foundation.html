웹 UI Foundation

Wanted Design System의 원칙과 토큰 구조를 참고해 정리한 PitchLog 웹 전용 최소 컴포넌트 세트입니다. 네이티브 플랫폼 컴포넌트는 제외했고, 깨진 원본 아이콘은 Lucide 스타일 아이콘으로 대체했습니다.

Web only Primary = 임시 컬러 Pretendard
Primary #3366FF는 Wanted 브랜드 컬러이며 PitchLog의 최종 브랜드 컬러가 아닙니다. 현재는 임시 Primary로만 사용하고, --pl-primary 한 곳만 교체하면 전체가 전환되도록 구성했습니다.

  • StatusBar, HomeBar, SafeArea, NavigationBar(Android)
  • BottomNavigation 및 iOS/Android Tab
  • DatePickerIOSWheel, PresentationPickerWheels
  • SafariBar, MobileTopNavigation(Float)
  • ActionArea 하단 고정 프리셋 — 웹은 우측 레일/모달 액션으로 대체
대체한 아이콘·에셋
  • 깨진 원본 아이콘 → Lucide 스타일 인라인 SVG(24 그리드, stroke 2, currentColor) 12종: search, bell, plus, check, x, chevron-left/right, chevrons-left/right, filter, more, info, image
  • Select의 caret → Lucide chevron-down SVG(배경 이미지)
  • 검은 사각형·빈 이미지 영역 → MediaPlaceholder(점선 프레임 + 비율 라벨)
  • 사람·회사 비트맵 → 원형 avatar placeholder
수정한 대비·레이아웃 문제
  • Tab의 검은 배경 위 어두운 텍스트 → 흰 배경 + 밑줄 선택 표시
  • Segmented 선택 라벨을 primary blue → text-strong으로 변경(대비 확보)
  • Badge 전경색을 accent 원본 대신 어두운 단계로 조정(positive #00893A, cautionary #A35A00, negative #D92020), solid Danger 버튼은 전용 토큰 --pl-negative-solid #D01919로 분리해 흰 텍스트 대비 4.5:1 확보
  • Pagination 오버플로 → flex-wrap, "페이지" 라벨 잘림 제거
  • 프레임 잘림·가로 스크롤 → 컨테이너 max-width 1060, auto-fit grid, min-width:0 + ellipsis
  • Placeholder 텍스트를 assistive 토큰으로 통일, disabled는 opacity 대신 전용 토큰 사용
