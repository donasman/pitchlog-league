# 1단계 — 파운데이션

## 만들 것

PitchLog의 시각 언어 기준판 한 장. 화면이 아니라 **부품 목록**이다.
이 단계에서 정해진 값이 이후 모든 화면에 그대로 쓰인다.

## 공통 전제 (모든 단계에 적용)

- 서비스: PitchLog — 유럽 5대 리그(EPL·라리가·분데스리가·세리에 A·리그 1)와 UCL의
  경기·순위·선수 기록 서비스. UI 언어는 한국어(영어 전환 지원).
- 라이트·다크 **양쪽 필수**.
- 기준 해상도: 데스크톱 1440×900, 모바일 390×844.
- 데이터는 6개 대회가 모두 들어있는 상태를 전제한다. EPL만 있는 화면을 그리지 않는다.

## 브랜드 컬러 (확정)

| 테마 | primary | hover | pressed |
|---|---|---|---|
| 라이트 | `#3366FF` | `#025FEB` | `#0054D1` |
| 다크 | `#6E93FF` | `#8FACFF` | `#A0BAFF` |

다크의 밝은 primary 위에는 흰 글자를 쓰지 않는다 (2.5:1로 무너짐). 어두운 글자 `#0B0B0D`를 쓴다.

## 표면·텍스트

| 역할 | 라이트 | 다크 |
|---|---|---|
| 페이지 배경 | `#F7F7F8` | `#121216` |
| 카드·입력 | `#FFFFFF` | `#1E1E23` |
| 본문 텍스트 | `#171719` | `#EDEDEF` |
| 보조 텍스트 | `rgba(55,56,60,.71)` | `#8E8E97` |
| 구분선 | `rgba(112,115,124,.22)` | `#33343A` |
| 컨트롤 경계 | `rgba(112,115,124,.80)` | — 3:1 확보용 |

## ⚠ 절대 규칙 — 파랑의 두 가지 의미

순위표에서 파랑은 **UCL 직행 구역**(`#3B82F6`)을 뜻한다. 브랜드 파랑과 색상환 8° 차이라
같은 화면에서 구분되지 않는다. 따라서 **형태로 분리한다.**

| 역할 | 허용 형태 | 금지 형태 |
|---|---|---|
| 브랜드 파랑 (누를 수 있는 것) | 채운 배경 + 흰 글자, 밑줄 텍스트 | 좌측 표시선, 행 배경 틴트 |
| 구역 파랑 (상태 표시) | 좌측 2px 표시선 + 4% 배경 틴트 + 범례 | 채운 배경, 링크 색 |

구체적으로:
1. **순위표 안에서 팀 이름을 브랜드 색으로 칠하지 않는다.** 본문 색을 쓰고 행 hover로 클릭 가능함을 나타낸다.
2. **활성 필터 칩은 틴트가 아니라 채운다.** 브랜드 파랑 배경 + 흰 글자.
3. **"전체 보기" 링크는 표 안이 아니라 섹션 헤더에 둔다.**

## 접근성

- 본문 텍스트 4.5:1 · 큰 텍스트(18.66px/700+) 3:1 · 컨트롤 경계 3:1
- 모든 인터랙티브 요소에 `:focus-visible` 외곽선 2px + offset 2px
- 상태를 색상 단독으로 구분하지 않는다
- `prefers-reduced-motion`에서 애니메이션 정지
- 모바일 터치 타깃 최소 44px

## 이 단계에서 그릴 것

### 1. 색 팔레트

위 브랜드·표면·텍스트 색을 라이트/다크 나란히. 각 칩에 hex와 용도를 함께 표기.

### 2. 의미색 — 이미 예약된 색

순위 구역과 상태에 묶여 있어 **브랜드가 쓸 수 없는** 색들이다.

| 용도 | 색 |
|---|---|
| UCL 직행 | `#3B82F6` |
| UCL 플레이오프 | `#EAB308` |
| 유로파리그 | `#F97316` |
| 컨퍼런스리그 | `#16A34A` |
| 강등 플레이오프 | `#F87171` |
| 강등 | `#DC2626` |
| 정상·승리 | `#00872D` (흰 글자 4.67:1) |
| 주의 | `#A86300` (흰 글자 4.71:1) |
| 오류·LIVE | `#D01919` (흰 글자 5.48:1) |

### 3. 타입 스케일

한글 본문 기준. Pretendard 또는 Noto Sans KR.
필요한 단계: 페이지 제목 / 섹션 헤더 / 카드 제목 / 본문 / 보조 / 캡션 / 숫자.

**숫자는 고정폭(`tabular-nums`)** — 순위·승점·스코어에서 자릿수가 바뀔 때 열이 흔들리면 안 된다.

### 4. 경기 상태 배지 8종

`예정` `LIVE` `하프타임` `종료` `재검증 중` `확정` `연기` `취소`

- **`종료`와 `확정`은 다른 상태다.** 그 사이가 `재검증 중`(숫자가 바뀔 수 있음)이며,
  이것이 이 서비스의 차별점이므로 시각적으로 드러나야 한다.
- `LIVE`·`하프타임`은 **색상 외 단서**(도트, 깜빡임)를 함께 갖는다.
- 배지는 **한 줄을 유지**한다. 한국어·영어 모두에서 줄바꿈되면 안 된다.

### 5. 화면 상태 4종

**로딩 / 오류 / 빈 결과 / 정상** — 네 가지를 각각 그린다.

- 로딩: 스켈레톤. 실제 콘텐츠와 같은 높이·개수여야 레이아웃이 튀지 않는다
- 오류: **빈 화면으로 위장 금지.** 무엇이 실패했는지와 재시도 수단
- 빈 결과: 오류와 시각적으로 구분. "필터를 바꿔보라"는 다음 행동 제시

### 6. 순위 구역 표기

좌측 2px 표시선 + 4% 배경 틴트 + **범례 텍스트** 3종 조합. 범례는 항상 노출(접지 않음).
색상 단독으로 구분하지 않는다.

### 7. 간격·모서리·그림자

간격 스케일(4~40px 9단계), 카드 모서리 반경, 그림자 3단계(카드/오버레이/모달).

## 산출물

라이트 1장 + 다크 1장. 각 색·배지·상태에 이름과 값이 붙어 있어야 한다.

## 다음으로 넘어가는 조건

브랜드 파랑과 UCL 구역 파랑이 **한 화면에 나란히 있을 때 구분되는지** 확인한다.
구분되지 않으면 형태 분리 규칙(위)이 제대로 적용되지 않은 것이다.
