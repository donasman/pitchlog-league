# 6단계 — 나머지 화면

## 만들 것

앞 단계에서 확정한 부품으로 조립하는 화면들. **새 부품을 만들지 않는다.**
새 부품이 필요하다고 느껴지면 2단계로 돌아가 거기서 정한다.

## 공통 전제 (모든 단계에 적용)

- 서비스: PitchLog — 유럽 5대 리그(EPL·라리가·분데스리가·세리에 A·리그 1)와 UCL의
  경기·순위·선수 기록 서비스. UI 언어는 한국어(영어 전환 지원).
- 라이트·다크 **양쪽 필수**.
- 기준 해상도: 데스크톱 1440×900, 모바일 390×844.
- 데이터는 6개 대회가 모두 들어있는 상태를 전제한다. EPL만 있는 화면을 그리지 않는다.

## 브랜드 컬러 (확정)

| 테마 | primary | hover | pressed |
|---|---|---|---|
| 라이트 | `#3366FF` | `#025FEB` | `#0054D1` |
| 다크 | `#6E93FF` | `#8FACFF` | `#A0BAFF` |

다크의 밝은 primary 위에는 흰 글자를 쓰지 않는다 (2.5:1로 무너짐). 어두운 글자 `#0B0B0D`를 쓴다.

## 표면·텍스트

| 역할 | 라이트 | 다크 |
|---|---|---|
| 페이지 배경 | `#F7F7F8` | `#121216` |
| 카드·입력 | `#FFFFFF` | `#1E1E23` |
| 본문 텍스트 | `#171719` | `#EDEDEF` |
| 보조 텍스트 | `rgba(55,56,60,.71)` | `#8E8E97` |
| 구분선 | `rgba(112,115,124,.22)` | `#33343A` |
| 컨트롤 경계 | `rgba(112,115,124,.80)` | — 3:1 확보용 |

## ⚠ 절대 규칙 — 파랑의 두 가지 의미

순위표에서 파랑은 **UCL 직행 구역**(`#3B82F6`)을 뜻한다. 브랜드 파랑과 색상환 8° 차이라
같은 화면에서 구분되지 않는다. 따라서 **형태로 분리한다.**

| 역할 | 허용 형태 | 금지 형태 |
|---|---|---|
| 브랜드 파랑 (누를 수 있는 것) | 채운 배경 + 흰 글자, 밑줄 텍스트 | 좌측 표시선, 행 배경 틴트 |
| 구역 파랑 (상태 표시) | 좌측 2px 표시선 + 4% 배경 틴트 + 범례 | 채운 배경, 링크 색 |

구체적으로:
1. **순위표 안에서 팀 이름을 브랜드 색으로 칠하지 않는다.** 본문 색을 쓰고 행 hover로 클릭 가능함을 나타낸다.
2. **활성 필터 칩은 틴트가 아니라 채운다.** 브랜드 파랑 배경 + 흰 글자.
3. **"전체 보기" 링크는 표 안이 아니라 섹션 헤더에 둔다.**

## 접근성

- 본문 텍스트 4.5:1 · 큰 텍스트(18.66px/700+) 3:1 · 컨트롤 경계 3:1
- 모든 인터랙티브 요소에 `:focus-visible` 외곽선 2px + offset 2px
- 상태를 색상 단독으로 구분하지 않는다
- `prefers-reduced-motion`에서 애니메이션 정지
- 모바일 터치 타깃 최소 44px

## 우선순위 P1 — 먼저

### 1. 대회 허브 `/competitions/:slug`

한 대회의 모든 것으로 가는 관문. 탭 또는 섹션으로:

- 순위 요약 (Top 8 + 전체 보기)
- 이번 라운드 경기
- 득점·도움 Top 5
- 참가 팀 목록
- **UCL만**: 녹아웃 대진 진입 버튼

국내 리그와 UCL이 **같은 레이아웃에 다른 섹션 구성**으로 들어간다.

### 2. UCL 녹아웃 `/competitions/champions-league/knockout`

가장 특이한 레이아웃. 플레이오프~결승 대진표.

- 각 타이: 두 팀 · 1차전 스코어 · 2차전 스코어 · **합산 점수** · 진출 팀 표시
- 미확정 팀은 `TBD`
- 진행 상태: 예정 / 1차전 종료 / 완료

⚠ **대진표는 가로로 넓다.** 데스크톱은 라운드별 열 배치, 모바일은 라운드별 세로 아코디언 등
**전혀 다른 레이아웃**이 필요하다. 두 가지를 각각 그린다.

### 3. 통계 `/stats`

- 대회 필터 (전체 합산 보기 포함)
- 득점 / 도움 / 카드 랭킹
- 각 행: 순위 · 선수 · 소속 팀 · 수치
- ⚠ 전체 합산 시 **대회별 분해** 표시 — 예: `12골 = EPL 9 + UCL 3`

### 4. 팀 상세 `/teams/:slug`

엠블럼 · 이름 · 홈구장 · 참가 대회 / 현재 순위(대회별로 여러 개일 수 있음) /
최근 경기 · 다음 경기 / 스쿼드 목록.

### 5. 팀 일정 `/teams/:slug/fixtures`

**대회 필터가 핵심**이다 (전체 / 국내 리그 / UCL). 기본값은 전체.
과거·미래를 한 흐름으로 보여주되 **"오늘" 위치를 표시**한다.

### 6. 선수 상세 `/players/:slug`

사진 · 이름 · 등번호 · 포지션 · 소속 팀 · 국적 /
시즌 기록 — **대회별 분리 + 전체 합산 토글** / 출전 · 골 · 도움 · 카드 · 출전 시간.

## 우선순위 P2 — 이어서

### 7. 대회 목록 `/competitions`

6개 대회 카드. 각 카드에 현재 시즌 · 진행 상태 · 선두 팀.

### 8. 팀 목록 `/teams`

대회·시즌 필터가 있는 팀 그리드. ⚠ **팀 수를 20으로 고정하지 않는다** (리그마다 다르다).

### 9. 404

홈 · 경기 · 순위로 가는 링크 제공.
