# 2단계 — 공통 컴포넌트

## 만들 것

5개 이상의 화면에서 반복되는 부품들. **이 단계가 가장 중요하다** —
여기서 확정하면 나머지 화면이 빨라지고, 대충 넘어가면 전부 다시 손대게 된다.

1단계에서 정한 색·타이포·간격을 그대로 쓴다.

## 공통 전제 (모든 단계에 적용)

- 서비스: PitchLog — 유럽 5대 리그(EPL·라리가·분데스리가·세리에 A·리그 1)와 UCL의
  경기·순위·선수 기록 서비스. UI 언어는 한국어(영어 전환 지원).
- 라이트·다크 **양쪽 필수**.
- 기준 해상도: 데스크톱 1440×900, 모바일 390×844.
- 데이터는 6개 대회가 모두 들어있는 상태를 전제한다. EPL만 있는 화면을 그리지 않는다.

## 브랜드 컬러 (확정)

| 테마 | primary | hover | pressed |
|---|---|---|---|
| 라이트 | `#3366FF` | `#025FEB` | `#0054D1` |
| 다크 | `#6E93FF` | `#8FACFF` | `#A0BAFF` |

다크의 밝은 primary 위에는 흰 글자를 쓰지 않는다 (2.5:1로 무너짐). 어두운 글자 `#0B0B0D`를 쓴다.

## 표면·텍스트

| 역할 | 라이트 | 다크 |
|---|---|---|
| 페이지 배경 | `#F7F7F8` | `#121216` |
| 카드·입력 | `#FFFFFF` | `#1E1E23` |
| 본문 텍스트 | `#171719` | `#EDEDEF` |
| 보조 텍스트 | `rgba(55,56,60,.71)` | `#8E8E97` |
| 구분선 | `rgba(112,115,124,.22)` | `#33343A` |
| 컨트롤 경계 | `rgba(112,115,124,.80)` | — 3:1 확보용 |

## ⚠ 절대 규칙 — 파랑의 두 가지 의미

순위표에서 파랑은 **UCL 직행 구역**(`#3B82F6`)을 뜻한다. 브랜드 파랑과 색상환 8° 차이라
같은 화면에서 구분되지 않는다. 따라서 **형태로 분리한다.**

| 역할 | 허용 형태 | 금지 형태 |
|---|---|---|
| 브랜드 파랑 (누를 수 있는 것) | 채운 배경 + 흰 글자, 밑줄 텍스트 | 좌측 표시선, 행 배경 틴트 |
| 구역 파랑 (상태 표시) | 좌측 2px 표시선 + 4% 배경 틴트 + 범례 | 채운 배경, 링크 색 |

구체적으로:
1. **순위표 안에서 팀 이름을 브랜드 색으로 칠하지 않는다.** 본문 색을 쓰고 행 hover로 클릭 가능함을 나타낸다.
2. **활성 필터 칩은 틴트가 아니라 채운다.** 브랜드 파랑 배경 + 흰 글자.
3. **"전체 보기" 링크는 표 안이 아니라 섹션 헤더에 둔다.**

## 접근성

- 본문 텍스트 4.5:1 · 큰 텍스트(18.66px/700+) 3:1 · 컨트롤 경계 3:1
- 모든 인터랙티브 요소에 `:focus-visible` 외곽선 2px + offset 2px
- 상태를 색상 단독으로 구분하지 않는다
- `prefers-reduced-motion`에서 애니메이션 정지
- 모바일 터치 타깃 최소 44px

## 이 단계에서 그릴 것

### 1. 앱 헤더

로고, 주 메뉴(경기·순위·팀·통계), 검색, 언어 토글(한/EN), 테마 토글.
데스크톱과 모바일(메뉴 접기) 두 가지.

### 2. 대회 선택기 ★

**가장 많이 반복되는 컨트롤.** 6개 대회 + "전체".

- 축약 표기: `EPL` `LaLiga` `BL` `SA` `L1` `UCL`
- 상태 3종: 기본 / hover / **활성(채운 배경 + 흰 글자)**
- 다중 선택형(홈 상단 필터)과 단일 선택형(사이드바) 두 변형
- ⚠ 활성 칩을 틴트 배경 + 파란 글자로 만들지 않는다 — 구역 표시와 같은 층위로 읽힌다

### 3. 경기 카드 ★

3가지 크기가 필요하다.

| 변형 | 쓰이는 곳 | 담을 것 |
|---|---|---|
| 히어로 | 홈 LIVE 메인 | 두 팀, 스코어, 상태 배지, 대회·라운드, 경과 시간 |
| 기본 | 홈 보조, 목록 | 두 팀, 스코어, 상태 배지, 대회 |
| 컴팩트 | 최근 결과, 다음 경기 3열 | 두 팀, 스코어 또는 킥오프 시각 |

각각 상태 8종 중 최소 `예정`·`LIVE`·`재검증 중`·`확정` 4가지를 그린다.

⚠ **긴 팀명 처리를 여기서 정한다.** `브라이턴 앤 호브 알비온`,
`Borussia Mönchengladbach`가 들어가도 깨지지 않아야 한다.
말줄임 / 축약명 전환 / 줄바꿈 중 하나를 골라 일관되게 적용한다.

### 4. 순위표 행 ★

열: 순위 · 팀 · 경기 · 승 · 무 · 패 · 득점 · 실점 · 득실차 · 승점 · 최근 5경기 폼

- 구역별 좌측 표시선 + 배경 틴트 (1단계 의미색)
- ⚠ **팀 이름은 본문 색.** 브랜드 파랑으로 칠하지 않는다
- 폼 배지(승/무/패 5개)
- 데스크톱 행 + **모바일 축약 행** 두 가지

### 5. 필터 바

대회 · 시즌 · 팀 · 라운드 · 날짜 — 최대 5개가 동시에 붙는다.
**모바일 처리 방식을 여기서 정한다**: 접기 / 바텀시트 / 가로 스크롤 칩 중 하나.

### 6. 버튼·링크

주요 버튼(채움) / 보조 버튼(외곽선) / 텍스트 링크.
각각 기본·hover·pressed·비활성·포커스 5개 상태.

### 7. 기타 반복 요소

- 팀 엠블럼 (있을 때 / 없을 때 대체 표시)
- 선수 아바타
- 데이터 기준 시각 표기 ("13:42 기준")
- 섹션 헤더 + "전체 보기" 링크

## 산출물

부품 시트 라이트/다크 각 1장. 각 부품의 변형과 상태가 모두 보여야 한다.

여기서 통과하지 못하면 홈과 순위 화면을 그려도 다시 돌아오게 된다.
