# 7단계 — 알림

## 만들 것

경기 이벤트를 사용자에게 알리는 화면 전체. **두 종류를 함께 설계한다.**

| 종류 | 언제 | 무엇이 필요한가 |
|---|---|---|
| **인앱 알림** | 사이트를 보고 있을 때 | Socket.io (Phase 2에 이미 있음) |
| **푸시 알림** | 사이트를 안 보고 있을 때 | Service Worker + 구독 저장 (신규) |

⚠ 이 서비스는 **로그인이 없다.** 알림 설정은 브라우저에 저장되고,
푸시 구독은 계정이 아니라 브라우저 단위로 서버에 기록된다.
따라서 **"내 알림"이 기기마다 다르다**는 점을 화면이 숨기지 않아야 한다.

## 공통 전제 (모든 단계에 적용)

- 서비스: PitchLog — 유럽 5대 리그(EPL·라리가·분데스리가·세리에 A·리그 1)와 UCL의
  경기·순위·선수 기록 서비스. UI 언어는 한국어(영어 전환 지원).
- 라이트·다크 **양쪽 필수**.
- 기준 해상도: 데스크톱 1440×900, 모바일 390×844.
- 탭은 `경기 · 순위 · 팀 · 통계` 4개. 홈은 로고 클릭으로 간다.

## ⚠ 절대 규칙 — 파랑의 두 가지 의미

브랜드 파랑과 UCL 구역 파랑이 색상환 8° 차이다. **형태로 분리한다.**

| 역할 | 허용 형태 | 금지 형태 |
|---|---|---|
| 브랜드 파랑 (누를 수 있는 것) | 채운 배경 + 흰 글자, 밑줄 텍스트 | 좌측 표시선, 배경 틴트 |
| 구역 파랑 (상태 표시) | 좌측 2px 표시선 + 4% 틴트 + 범례 | 채운 배경, 링크 색 |

## 접근성

- 본문 4.5:1 · 큰 텍스트 3:1 · 컨트롤 경계 3:1
- 모든 인터랙티브 요소에 `:focus-visible` 외곽선 2px + offset 2px
- 상태를 색상 단독으로 구분하지 않는다
- `prefers-reduced-motion`에서 애니메이션 정지
- 모바일 터치 타깃 최소 44px

## 이 단계에서 그릴 것

### 1. 인앱 토스트 ★

경기 이벤트가 발생했을 때 화면 구석에 뜨는 알림.

| 종류 | 내용 | 색 |
|---|---|---|
| 골 | 팀 엠블럼 · 득점자 · 스코어 · 경과 시간 | 기본 |
| 킥오프 | 두 팀 · 대회 | 기본 |
| 경기 종료 | 최종 스코어 | 기본 |
| **기록 확정** | "이 경기 기록이 확정됐습니다" | `#007833` |

⚠ **확정 알림이 이 서비스의 특징**이다. 다른 서비스에는 없다.
경기가 끝난 뒤 몇 시간 지나 오는 알림이라, 골 알림과 시각적으로 구분한다.

그려야 할 것:
- 단일 토스트
- **여러 개가 동시에 쌓였을 때** (골이 연달아 들어가면 흔하다) — 최대 개수와 쌓이는 방식
- 자동 사라짐 vs 수동 닫기 — 골은 자동, 확정은 수동 등 규칙을 정한다
- 클릭하면 해당 경기 상세로

### 2. 헤더 벨 아이콘 + 안 읽은 개수

- 안 읽은 알림 개수 배지. 0일 때는 배지를 숨긴다
- ⚠ 개수 배지가 빨강이면 LIVE·오류 색과 겹친다. **브랜드 파랑 채움**을 쓴다
- 99개 넘으면 `99+`

### 3. 알림 패널 (벨 클릭 시)

- 최근 알림 목록 — 시각 · 아이콘 · 한 줄 요약
- 읽음 / 안 읽음 구분 (배경 틴트 + 좌측 점)
- "모두 읽음" 버튼
- 하단 "알림 설정" 링크
- **비어 있을 때** 화면 — 첫 방문자는 반드시 이 상태를 본다

데스크톱은 드롭다운, 모바일은 전체 화면 또는 바텀시트.

### 4. 권한 요청 — 2단계로 ★

브라우저 권한 창을 **바로 띄우지 않는다.** 거절하면 되돌릴 수 없고, 거절률도 높다.

먼저 우리 화면에서 설명하고, 사용자가 동의했을 때만 브라우저 창을 띄운다.

```
[우리 카드]  "골이 들어가면 알려드릴까요?"
             관심 팀 경기만 보냅니다. 언제든 끌 수 있습니다.
             [나중에]  [알림 받기]
                            ↓ 누르면
[브라우저]   권한 요청 창
```

그려야 할 상태 넷:
- 아직 안 물어봄 (설정 화면에 "알림 켜기" 버튼)
- 우리 카드가 뜬 상태
- **허용됨**
- **거부됨** — 브라우저 설정에서 바꿔야 한다는 안내. 우리 버튼으로는 못 되돌린다

### 5. 알림 설정 화면

무엇을 받을지 고르는 화면. 두 축이다.

**무엇에 대해**
- 관심 팀 (팀 검색해서 추가/삭제)
- 관심 대회 (6개 중 선택)

**어떤 일이**
- 킥오프 · 골 · 경기 종료 · 기록 확정

**어디로**
- 인앱만 / 푸시도 (푸시는 권한 필요)

⚠ **기기마다 다르다는 것을 알린다.** "이 브라우저에서만 적용됩니다" 같은 한 줄이 필요하다.
로그인이 없어서 다른 기기와 동기화되지 않는다.

### 6. 푸시 알림 내용

OS가 그리지만 **문구와 아이콘은 우리가 정한다.**

```
제목: 리버풀 2 - 1 첼시
본문: 68' 살라
아이콘: 팀 엠블럼 (또는 PitchLog 로고)
```

- 제목에 스코어를 넣어서 알림창만 봐도 알 수 있게 한다
- 누르면 해당 경기 상세로 이동
- ⚠ 한 경기에서 골이 연달아 나면 알림이 쌓인다. **같은 경기 알림은 교체**한다 (tag 사용)

## 산출물

- 토스트 4종 (골 · 킥오프 · 종료 · 확정) 라이트/다크
- 토스트 다중 스택 1장
- 헤더 벨 (배지 있음 / 없음)
- 알림 패널 (내용 있음 / 비어 있음) 데스크톱 + 모바일
- 권한 요청 카드 + 거부됨 상태
- 알림 설정 화면 데스크톱 + 모바일

## 다음으로 넘어가는 조건

1. 골 알림과 **확정 알림이 한눈에 구분**되는가
2. 권한을 **거부한 사용자**가 막다른 길에 갇히지 않는가
3. "이 기기에서만 적용된다"는 것이 설정 화면에서 읽히는가
