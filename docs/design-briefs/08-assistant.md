# 8단계 — AI 어시스턴트

## 만들 것

자연어로 일정·순위·기록을 묻는 패널. **Phase 5 기능이지만 디자인은 미리 한다.**

## ⚠ 이 챗봇은 일반 챗봇과 다르게 그려야 한다

백엔드 원칙이 UI를 규정한다.

> **AI는 숫자를 만들지 않는다.** 데이터베이스와 외부 API에 직접 접근하지 않고,
> 정해진 조회 도구의 결과만 사용한다. 집계·비교·순위·진출 판정은 전부 백엔드가 확정한다.
> 답변에는 데이터 기준 시각과 근거를 함께 제공한다.

말풍선만 있는 챗봇을 그리면 이 원칙이 화면에서 사라진다.
사용자는 AI가 숫자를 지어낸 것인지 조회한 것인지 알 수 없게 된다.

**그래서 답변에 반드시 붙는 것이 셋이다.**

| # | 요소 | 왜 |
|---|---|---|
| 1 | **근거 카드** | 어떤 데이터를 조회했는지 펼쳐볼 수 있어야 한다 |
| 2 | **데이터 기준 시각** | "13:42 기준" — 언제 데이터인지 |
| 3 | **신뢰도 표기** | 재검증 중인 값을 인용하면 채팅 안에서도 그 배지가 보인다 |

그리고 **숫자는 문장에 섞지 않고 데이터 카드로 렌더링한다.**
"리버풀이 65점으로 1위입니다"를 문장으로만 쓰면 지어낸 것과 구분되지 않는다.
순위 조각·표·경기 카드를 그대로 답변 안에 넣는다.

## 공통 전제 (모든 단계에 적용)

- 서비스: PitchLog — 유럽 5대 리그(EPL·라리가·분데스리가·세리에 A·리그 1)와 UCL의
  경기·순위·선수 기록 서비스. UI 언어는 한국어(영어 전환 지원).
- 라이트·다크 **양쪽 필수**.
- 기준 해상도: 데스크톱 1440×900, 모바일 390×844.
- 탭은 `경기 · 순위 · 팀 · 통계` 4개. 홈은 로고 클릭으로 간다.

## ⚠ 절대 규칙 — 파랑의 두 가지 의미

브랜드 파랑과 UCL 구역 파랑이 색상환 8° 차이다. **형태로 분리한다.**

| 역할 | 허용 형태 | 금지 형태 |
|---|---|---|
| 브랜드 파랑 (누를 수 있는 것) | 채운 배경 + 흰 글자, 밑줄 텍스트 | 좌측 표시선, 배경 틴트 |
| 구역 파랑 (상태 표시) | 좌측 2px 표시선 + 4% 틴트 + 범례 | 채운 배경, 링크 색 |

## 접근성

- 본문 4.5:1 · 큰 텍스트 3:1 · 컨트롤 경계 3:1
- 모든 인터랙티브 요소에 `:focus-visible` 외곽선 2px + offset 2px
- 상태를 색상 단독으로 구분하지 않는다
- `prefers-reduced-motion`에서 애니메이션 정지
- 모바일 터치 타깃 최소 44px

## 진입 방식 — 전역 패널을 권장

PRD 미결정 #5가 "전용 화면(`/assistant`) vs 전역 패널"로 열려 있다. **전역 패널을 권한다.**

이유는 **화면 문맥** 때문이다. 순위표를 보다가 "3위 팀 최근 폼은?"이라고 물으면
그 "3위 팀"이 무엇인지 패널이 알아야 한다. 전용 화면으로 가면 문맥이 끊긴다.

- 데스크톱 — 우측에서 밀려 나오는 패널. 본문은 그대로 보인다
- 모바일 — 바텀시트. 위로 끌어올리면 전체 화면

진입 버튼은 **우하단 고정 버튼**(FAB) 또는 헤더 아이콘. 알림 벨과 나란히 두지 않는다 —
성격이 다르고, 벨 옆에 두면 알림의 일부로 읽힌다.

## 이 단계에서 그릴 것

### 1. 닫힌 상태 — 진입 버튼

- 브랜드 파랑 채움 (형태 분리 규칙)
- 아이콘은 말풍선이 아니라 이 서비스에 맞는 것 — 검색·질문 성격
- 스크롤해도 자리를 지킨다

### 2. 빈 상태 ★

처음 열었을 때. **여기가 가장 중요하다.**

사용자는 "무엇을 물어볼 수 있는지" 모른다. 그래서 **예시 질문 3~4개를 제시**한다.
이 서비스가 답할 수 있는 것의 범위를 예시가 알려준다.

```
· 손흥민 이번 시즌 기록 알려줘
· 리버풀 다음 경기 언제야?
· EPL 상위 4팀 최근 5경기 비교해줘
· 챔피언스리그 16강 올라간 팀은?
```

한 줄 안내도 함께: "일정 · 순위 · 선수 기록을 물어보세요. 숫자는 데이터베이스에서 직접 가져옵니다."

### 3. 대화 말풍선

- 사용자 메시지 — 우측 정렬, 브랜드 파랑 채움
- AI 답변 — 좌측, 카드 배경. 아바타는 로고 마크

### 4. 데이터 카드 (답변 안에 들어가는 것) ★

답변에 숫자가 있으면 카드로 렌더링한다. 최소 네 종류가 필요하다.

| 종류 | 내용 | 재사용 |
|---|---|---|
| 순위 조각 | 해당 팀 앞뒤 2팀 포함 | 순위표 행 컴포넌트 |
| 경기 카드 | 일정·결과 | 경기 카드 컴포넌트 |
| 선수 기록 | 출전·골·도움 (대회별 분리) | 통계 행 |
| 비교 표 | 두 팀·선수 나란히 | 신규 |

⚠ **기존 컴포넌트를 그대로 쓴다.** 챗봇 전용 카드를 새로 만들면 두 벌을 관리하게 된다.

### 5. 근거 카드 ★

답변 하단에 접혀 있고, 누르면 펼쳐진다.

```
▸ 근거 보기
   ────────────────────────
   조회: 선수 시즌 기록 (손흥민, EPL, 2026-27)
   기준: 2026-09-03 13:42
   출처: API-Football → PitchLog DB
```

- 접힌 상태가 기본. 답변을 가리지 않는다
- ⚠ **재검증 중인 값이 섞여 있으면** 접힌 상태에서도 배지가 보여야 한다

### 6. 신뢰도 표기가 답변에 섞일 때

```
어제 리버풀 경기 기록은 아직 확정되지 않았습니다. [↻ 재검증 중]
현재 값은 3-1이고, 공식 기록이 확정되면 바뀔 수 있습니다.
```

이 상태를 반드시 한 장 그린다. **이게 이 챗봇의 존재 이유**를 보여주는 화면이다.

### 7. 그 밖의 상태

- **생각 중** — 도구를 호출하는 동안. "순위를 조회하는 중" 같이 무엇을 하는지 보여준다
- **답할 수 없음** — 조회 도구로 답이 안 되는 질문 ("누가 우승할까?").
  솔직하게 못 한다고 하고, 할 수 있는 것을 제안한다
- **오류** — 백엔드 실패. 재시도 수단
- **긴 답변** — 스크롤과 입력창의 관계

## 산출물

- 진입 버튼 (닫힌 상태)
- 빈 상태 — 데스크톱 패널 + 모바일 바텀시트
- 대화 중 (데이터 카드 2종 이상 포함) 라이트/다크
- **근거 카드 펼친 상태** 1장
- **재검증 중 값을 인용한 답변** 1장
- 생각 중 · 답할 수 없음 · 오류

## 다음으로 넘어가는 조건

1. 답변의 숫자가 **조회된 것**임이 화면에서 읽히는가 — 지어낸 것처럼 보이면 실패
2. 근거 카드가 답변을 **가리지 않으면서** 존재를 알리는가
3. 재검증 중인 값을 인용한 답변이 확정된 값과 **구분**되는가
