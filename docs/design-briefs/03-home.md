# 3단계 — 홈

## 만들 것

`/` 홈 화면. 데스크톱 1440×900과 모바일 390×844.

사용자의 가장 잦은 동선은 **"지금 뭐 하고 있지"** 다. 홈은 이것만을 위해 최적화한다.
1·2단계의 부품을 그대로 조립한다. 새 부품을 만들지 않는다.

## 공통 전제 (모든 단계에 적용)

- 서비스: PitchLog — 유럽 5대 리그(EPL·라리가·분데스리가·세리에 A·리그 1)와 UCL의
  경기·순위·선수 기록 서비스. UI 언어는 한국어(영어 전환 지원).
- 라이트·다크 **양쪽 필수**.
- 기준 해상도: 데스크톱 1440×900, 모바일 390×844.
- 데이터는 6개 대회가 모두 들어있는 상태를 전제한다. EPL만 있는 화면을 그리지 않는다.

## 브랜드 컬러 (확정)

| 테마 | primary | hover | pressed |
|---|---|---|---|
| 라이트 | `#3366FF` | `#025FEB` | `#0054D1` |

## ⚠ 절대 규칙 — 파랑의 두 가지 의미

순위표에서 파랑은 **UCL 직행 구역**(`#3B82F6`)을 뜻한다. 브랜드 파랑과 색상환 8° 차이라
같은 화면에서 구분되지 않는다. 따라서 **형태로 분리한다.**

| 역할 | 허용 형태 | 금지 형태 |
|---|---|---|
| 브랜드 파랑 (누를 수 있는 것) | 채운 배경 + 흰 글자, 밑줄 텍스트 | 좌측 표시선, 행 배경 틴트 |
| 구역 파랑 (상태 표시) | 좌측 2px 표시선 + 4% 배경 틴트 + 범례 | 채운 배경, 링크 색 |

구체적으로:
1. **순위표 안에서 팀 이름을 브랜드 색으로 칠하지 않는다.** 본문 색을 쓰고 행 hover로 클릭 가능함을 나타낸다.
2. **활성 필터 칩은 틴트가 아니라 채운다.** 브랜드 파랑 배경 + 흰 글자.
3. **"전체 보기" 링크는 표 안이 아니라 섹션 헤더에 둔다.**

## 접근성

- 본문 텍스트 4.5:1 · 큰 텍스트(18.66px/700+) 3:1 · 컨트롤 경계 3:1
- 모든 인터랙티브 요소에 `:focus-visible` 외곽선 2px + offset 2px
- 상태를 색상 단독으로 구분하지 않는다
- `prefers-reduced-motion`에서 애니메이션 정지
- 모바일 터치 타깃 최소 44px

## 첫 화면 (1440×900, 스크롤 전)에 들어가야 하는 것

순서대로:

1. **대회 필터 칩** — 6개 대회 다중 선택 + 전체
2. **요약 스트립** — 진행 중 경기 수 / 오늘 경기 수 / EPL 선두 / EPL 득점 1위
3. **LIVE 히어로 카드** — 진행 중 경기 1건을 크게. 없으면 다음 예정 경기로 대체
4. **보조 경기 카드 2건**
5. **오늘의 경기 목록** — 최대 8행
6. **사이드바** — 대회 선택기 + 순위 Top5 + 득점 Top5 + UCL 녹아웃 진출 팀

스크롤 아래: 최근 결과 / 다음 경기 / UCL 16강 3열.

## 레이아웃

본문 + 사이드바 2열. 사이드바 고정폭(340px 내외), 본문 가변.
모바일에서는 사이드바가 본문 아래로 내려간다.

## ⚠ 주의할 것

**사이드바의 대회 선택기는 상단 필터 칩과 독립적으로 동작한다.**

- 상단 = 경기 목록을 거르는 필터 (다중 선택)
- 사이드바 = 순위·득점을 볼 대회 선택 (단일 선택)

같은 컨트롤로 오해되지 않도록 시각적으로 구분한다. 이게 이 화면의 가장 큰 함정이다.

## 모바일에서 결정할 것

390px에서 위 6개 블록의 **순서와 우선순위**를 다시 정한다.
데스크톱 순서를 그대로 세로로 쌓으면 사이드바 콘텐츠가 너무 아래로 밀린다.
