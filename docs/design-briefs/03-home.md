# 3단계 — 홈 (제품 앞장)

## 만들 것

`/` 홈 화면. 데스크톱 1440×900과 모바일 390×844.

**주의: 이건 데이터 화면이 아니다.** 경기 탭이 이미 라이브 히어로·대회별 그룹·순위 Top5·
팀 정보 패널까지 전부 담고 있다. 홈이 같은 걸 요약해서 보여주면 **열등한 복사본**이 된다.

홈이 맡는 일은 셋이다.

1. 처음 온 사람에게 **이 서비스가 뭔지** 알린다
2. **지금 살아있다**는 것을 보여준다
3. 각 탭으로 **보낸다**

## 공통 전제 (모든 단계에 적용)

- 서비스: PitchLog — 유럽 5대 리그(EPL·라리가·분데스리가·세리에 A·리그 1)와 UCL의
  경기·순위·선수 기록 서비스. UI 언어는 한국어(영어 전환 지원).
- 라이트·다크 **양쪽 필수**.
- 기준 해상도: 데스크톱 1440×900, 모바일 390×844.
- 데이터는 6개 대회가 모두 들어있는 상태를 전제한다.

|---|---|---|---|

다크의 밝은 primary 위에는 흰 글자를 쓰지 않는다. 어두운 글자 `#0B0B0D`를 쓴다.

## ⚠ 절대 규칙 — 파랑의 두 가지 의미

순위표에서 파랑은 **UCL 직행 구역**(`#3B82F6`)이다. 브랜드 파랑과 색상환 8° 차이라
같은 화면에서 구분되지 않는다. **형태로 분리한다.**

| 역할 | 허용 형태 | 금지 형태 |
|---|---|---|
| 브랜드 파랑 (누를 수 있는 것) | 채운 배경 + 흰 글자, 밑줄 텍스트 | 좌측 표시선, 배경 틴트 |
| 구역 파랑 (상태 표시) | 좌측 2px 표시선 + 4% 틴트 + 범례 | 채운 배경, 링크 색 |

## 접근성

- 본문 4.5:1 · 큰 텍스트 3:1 · 컨트롤 경계 3:1
- 모든 인터랙티브 요소에 `:focus-visible` 외곽선 2px + offset 2px
- 상태를 색상 단독으로 구분하지 않는다
- `prefers-reduced-motion`에서 애니메이션 정지
- 모바일 터치 타깃 최소 44px

## 네비게이션

**탭에 홈을 추가하지 않는다.** 탭은 `경기 · 순위 · 팀 · 통계` 4개를 유지하고,
**좌측 PitchLog 로고를 누르면 홈으로** 온다. 홈에서는 로고 아래 밑줄이 보인다.

## 화면 구성 — 위에서부터

### ① 히어로 — 좌우 2열

**왼쪽 — 말**

- 헤드라인 한 줄: 무엇을 다루는 서비스인가 (예: "유럽 5대 리그와 UCL, 한 곳에서")
- 부제 2줄: 이 서비스의 차별점을 평이한 말로.
  "진행 중인 경기는 실시간으로, 끝난 경기는 공식 기록이 확정될 때까지 표시해 둡니다."
- 버튼 2개: **오늘 경기 보기**(주) · 순위표(보조)

**오른쪽 — 살아있음의 증거** ★

이 화면에서 가장 중요한 요소다. 마케팅 문구만 있으면 죽은 페이지로 읽힌다.

- 제목: 깜빡이는 도트 + "지금 N경기 진행 중" + 데이터 기준 시각
- 그 아래 **진행 중인 경기의 스코어만 4줄** (팀명 + 점수 + 경과 시간)

⚠ **경기 카드를 쓰지 않는다.** 경기 탭의 카드와 같은 형태면 중복으로 보인다.
얇은 스코어 줄(티커에 가까운 형태)로 만든다.

⚠ **진행 중인 경기가 0건일 때**를 반드시 그린다. "다음 경기 오늘 22:00" 같은
다음 킥오프 안내로 대체한다. 비어 보이면 안 된다.

### ② 6개 대회 현황 — 3×2 그리드

이 서비스가 6개 대회를 다룬다는 것을 증명하는 자리다. 각 카드에:

- 대회 엠블럼 + 이름
- 우상단 상태 배지 — `LIVE 1` (빨강 채움) 또는 `예정 2` (외곽선)
- 현재 라운드/스테이지 — "28라운드 진행 중", UCL은 "8강 1차전"
- 하단 구분선 아래 선두 팀 + 승점 (UCL은 진행 중 경기 스코어)

카드 전체가 클릭 대상이고, 누르면 그 대회의 순위로 간다.

### ③ 차별점 3개 — 3열

각 열은 **작은 시각 요소 + 제목 + 3줄 설명** 구조다. 아이콘을 쓰지 않고
**실제 UI 조각**을 쓴다 — 그래야 설명이 아니라 증거가 된다.

| 열 | 시각 요소 | 제목 |
|---|---|---|
| 1 | 상태 배지 3개 실물 (LIVE / 재검증 중 / 확정) | 경기 종료 ≠ 기록 확정 |
| 2 | 순위 구역 색 막대 6칸 | 리그와 UCL을 한 화면에서 |
| 3 | 한/영 이름 칩 (손흥민 / Son) | 한국어로 찾고 한국어로 읽기 |

⚠ 1번이 이 서비스의 핵심 메시지다. 가장 왼쪽에 둔다.

### ④ 바로 가기 — 3열 카드

순위 · 통계 · 팀. 각 카드에 **미리보기 3행**을 넣는다 (순위는 Top3, 통계는 득점 1·2·5위).

⚠ **전체 표를 넣지 않는다.** 3행이면 "여기 가면 더 있다"가 전달된다.
그 이상은 순위 탭의 일이다.

### ⑤ 푸터

데이터 출처(API-Football), 시즌, 데이터 기준 시각.

## 모바일 (390)

세로로 쌓되 **순서를 바꾼다.**

```
헤드라인 + 부제 + 버튼
라이브 펄스          ← 데스크톱의 오른쪽 열이 여기로
6개 대회 (1열 또는 2열)
차별점 3개 (1열)
바로 가기 (1열)
```

차별점 3개는 모바일에서 길어진다. **설명을 2줄로 줄이거나 접는다.**

## 산출물

- 데스크톱 라이트 / 데스크톱 다크
- 모바일 라이트 / 모바일 다크
- **진행 중 경기 0건 상태** 1장 (히어로 오른쪽이 다음 킥오프 안내로 바뀐 모습)

## 다음으로 넘어가는 조건

1. 스크롤 없이 **이 서비스가 무엇인지** 알 수 있는가
2. 스크롤 없이 **지금 살아있다**는 것이 보이는가
3. 경기 탭 스크린샷과 나란히 놓았을 때 **같은 화면으로 보이지 않는가**

3번이 이 단계의 진짜 시험이다. 홈이 경기 탭의 요약처럼 보이면 다시 그린다.
