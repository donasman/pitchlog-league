# 에이전트 파이프라인 실측 기록

> `pitchlog-agent-run` 으로 한 판 돌릴 때마다 한 줄. 구조를 고치는 근거는 이 표에서만 나온다.
> 안 깨졌으면 안 고친다. 세 판 연속 같은 자리가 깨지면 그때 고친다.
