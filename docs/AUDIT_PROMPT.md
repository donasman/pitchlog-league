## 검사 4 · null 처리 (DATA_RULES 3장)
Mock 이 실제 API 동작을 반영해 redCards 를 0 대신 null 로 준다.

- null → 0 으로 바꿔야 하는 것: 카드·오프사이드·슈팅·파울·태클·듀얼·드리블·페널티
- null 을 유지해야 하는 것: rating · expectedGoals · goalsPrevented
  ⚠ 평점을 0으로 바꾸면 랭킹에서 출전 안 한 선수가 최하위로 끼어든다
- 화면에 "-" 나 "NaN" 이나 "null" 이 뜨는 경로가 있는가

## 감사가 특히 잘 잡는 것

Foundation 감사(2026-09-02)에서 실제로 나온 11건의 종류다.

| 종류 | 예시 |
|---|---|
| 눈에 안 보이는 대비 미달 | 배지 전경 3.85:1 — 멀쩡해 보였다 |
| 알파 합성 착시 | 배지 배경이 알파라 페이지 배경 위에서 더 어두워짐 |
| 정의 자체가 없음 | 버튼·링크에 `:focus-visible`이 아예 없었다 |
| 경계가 안 보임 | 입력 테두리 1.32:1 |
| 색상 단독 의존 | 스위치 off 상태에 경계가 없었다 |

Mock 검증에서도 같은 일이 있었다 — 홀란 2골이 1골로 들어간 것,
득점자가 라인업에 없던 것, 등번호 중복. 전부 화면에서는 안 보였다.
